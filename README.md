# アメリカ政治とキリスト教思想史（2026年中間選挙とトランプ政権の深層）

第2次トランプ政権の権力構造、白人福音派の支持基盤、テクノリバタリアンの台頭を、アメリカ二大政党史とキリスト教2000年の深層（福音派・ディスペンセーション主義・キリスト教シオニズム・新使徒的改革 NAR）から読み解くインタラクティブ学習プラットフォーム。

---

## 🚀 主な機能とコンテンツ

- 🏛️ **2026年中間選挙前の議会勢力図**:
  - 上院（53 vs 47）・下院（220 vs 213）の勢力バランスと過半数ライン（51/218）ピン付きビジュアルバー。
- 🗺️ **全米州別・支持基盤マップ**:
  - 12×7 USカートグラム（レッドステート25州、ブルーステート18州、スイングステート7州の可視化）。
- 📊 **主要7教派の比較マトリックス**:
  - 白人福音派、南部バプテスト連盟（SBC）、主流派プロテスタント、カトリック、ペンテコステ派/NAR、長老派、東方正教会の信義・信徒数・政治スタンス徹底比較。
- 🎨 **政党再編と南北支持逆転史**:
  - 1860年代リンカーン共和党から、1960年代公民権運動、ニクソンの南部戦略、レーガン×モラル・マジョリティによる南部共和党王国化のタイムライン（民主党優位期は青、共和党優位期は赤で完全連動）。
- 👥 **トランプ政権と宗教・思想の人脈相関図**:
  - トランプを中心とするホワイトハウス信仰局、福音派指導者、シリコンバレー・テクノリバタリアン等の勢力ネットワーク。
- 🔍 **自然文・全文横断検索システム (`⌘K` / `Ctrl+K`)**:
  - 「福音派がトランプを支持する理由」等の自然文入力に対応し、該当箇所へ一発ジャンプ＆ハイライト。
- 📖 **キリスト教・米政治の重要用語集（単語帳）**:
  - 終末論、患難前携挙説、千年王国論、七つの山の覇権、キリスト教シオニズムなどの解説。
